Orgora Clipper

Clip the LinkedIn profile you are looking at into Orgora Charts. The extension runs on your computer. It does not send profile data to us — we have no servers.

Download Orgora Charts on the App Store

Safari (iPhone, iPad, and Mac) — already in the app

If you installed Orgora Charts, Clipper is already on the device. You do not download a separate plugin. Open profiles in Safari — the LinkedIn app does not share that login.

  1. Open Orgora Charts once so the device registers the extension.
  2. iPhone/iPad: Settings → Apps → Safari → Extensions → Orgora Clipper, turn it on.
    Mac: Safari → Settings → Extensions, check Orgora Clipper.
  3. Allow linkedin.com (Permissions → Allow).
  4. In Safari, open a LinkedIn profile (linkedin.com/in/…).
  5. Tap Clip to Orgora on the page, or the puzzle-piece in the address bar → Orgora Clipper → Clip to Orgora.
  6. Switch back to Orgora Charts. A banner lists people waiting, or open More → Import from LinkedIn.

Chrome — coming soon

The Chrome extension is coming to the Chrome Web Store. Chrome on iPhone and iPad cannot install extensions — use Safari there.

When it is live on a Mac:

  1. Open the Chrome Web Store and search Orgora Clipper.
  2. Click Add to Chrome.
  3. Open a LinkedIn profile in Chrome.
  4. Click Clip to Orgora on the page, or the toolbar icon.
  5. Chrome saves a small clip file. In Orgora Charts, open More → Import from LinkedIn and choose Import clip files….
