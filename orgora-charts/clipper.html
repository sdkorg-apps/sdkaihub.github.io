Orgora Clipper

Clip the LinkedIn profile you are looking at into Orgora Charts. The extension runs on your computer. It does not send profile data to us — we have no servers.

Download Orgora Charts on the App Store Download the Chrome extension

Safari (iPhone, iPad, and Mac) — already in the app

If you installed Orgora Charts, Clipper is already on the device. You do not download a separate plugin.

  1. Open Orgora Charts once so the system registers the extension.
  2. iPhone/iPad: Settings → Apps → Safari → Extensions → Orgora Clipper, turn it on, and allow linkedin.com.
    Mac: Safari → Settings → Extensions → check Orgora Clipper, and allow linkedin.com.
  3. Open the profile in Safari (the LinkedIn app does not share that login).
  4. Tap Clip to Orgora on the page, then switch back to Orgora Charts — a banner lists people waiting to be added.

Google Chrome (Mac)

Yes — the same Clipper works in Chrome. You do not write an extension. We already built it; adding it is free.

The one-click path is the Chrome Web Store (“Add to Chrome”). The listing is submitted and waiting on Google’s review (usually a few days). Until it is live, add the same free extension in four steps — no coding, no GitHub, no Terminal.

  1. Download Orgora Clipper and unzip it (double-click the zip). You should see a folder that contains a file named manifest.json.
  2. In Chrome, open chrome://extensions (paste that into the address bar).
  3. Turn on Developer mode (top right), then click Load unpacked and choose that unzipped folder.
  4. Pin Orgora Clipper from Chrome’s puzzle-piece menu. Open a LinkedIn profile and click Clip to Orgora.

Chrome saves a small clip file. In Orgora Charts, open the clip inbox (clipboard icon on the home screen) and choose Import clip files….

Chrome on iPhone and iPad cannot install extensions. Use Safari there.

What you are not doing

You are not creating a Chrome extension, paying a developer fee, or publishing anything. “Developer mode” only unlocks “Load unpacked” so Chrome will accept a folder we already packaged. Leave Developer mode on so the Clipper stays loaded.
